Multilingual Love Heart ❤️🌍

A little heart, a thousand feelings, and more than 20 ways to say I love you. ❤️

Multilingual Love Heart is a generative typography art project that transforms romantic words into a beautiful heart-shaped visual. Originally built in Python, the project has also been brought to the web, making it easy to experience and share from any device.

Every phrase carries the same feeling, no matter the language: I love you. 💌

🚀 How to Run

Option 1: Open the Web App

The easiest way to experience the project is through the live demo:

👉 https://loveyou-gray-delta.vercel.app/

No installation is required.

Option 2: Run the Web App Locally

Prerequisites: Git and Python installed on your system.

Clone the repository:

git clone https://github.com/shafiqahmed-786/loveYou.git

Navigate to the project directory:

cd loveYou

Start a local HTTP server:

python -m http.server 8000

Open your browser and visit:

http://localhost:8000

Make sure index.html is in the directory being served.

Option 3: Run the Original Python Version

Prerequisites: Python 3 installed.

Clone the repository and navigate to its directory, if you haven't already:

git clone https://github.com/shafiqahmed-786/loveYou.git
cd loveYou

Run the Python application:

python love.py

The Python version uses turtle and tkinter to render the animated heart in a desktop window. A graphical desktop environment is required.

💌 The Idea Behind It

Love doesn't belong to just one language.

It can be Te amo, Je t'aime, Saranghae, Main tumse pyaar karta hoon, or a thousand other beautiful expressions. The words may sound different, but the feeling behind them can be the same.

This project brings those expressions together in the shape of a heart—a little piece of generative art celebrating love across languages and cultures. ❤️🌎
